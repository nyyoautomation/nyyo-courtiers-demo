# AI for insurance brokers: live demo

No sign-up demo, fictional data only, replay mode (pre-recorded analyses).

- **English (international):** https://nyyoautomation.github.io/nyyo-courtiers-demo/
- **Français :** https://nyyoautomation.github.io/nyyo-courtiers-demo/fr/

Three use cases:

1. **Quote comparison and advice record**: insurer offers side by side on one coverage grid (limits, deductibles, exclusions), checked against the policy wording and the client's needs, then a client summary note ready for review.
2. **Renewal review**: coverage gaps between the current policy and the client's changed situation (new equipment, revenue, activities).
3. **Pre-filled claim notice** from the client's emails, photos and reports, with deadline and consistency checks.

Every result cites its source (document, page, clause), runs a contradiction check (confirm or dismiss each item) and shows a human-review banner. The tool gives no advice and sends nothing to an insurer or client. Live input checks, triage and Word export run in the browser.

Figures shown are estimates on the fictional sample, not promises. Pricing: on quote. Available on LaborX · Remote · Worldwide.
